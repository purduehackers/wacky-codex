# Projects

- Resolve the PH team and exact project before editing settings, domains, membership, or environment variables.
- List environment names and metadata without values. Copy secrets only through protected memory/files, never chat, Git, or command arguments.
- Scope variables to the requested development, preview, production, branch, or custom environment. Do not default a credential to every environment.
- A new deployment is needed to use changed deployed environment variables.
- Pausing affects production availability. Removing a project domain detaches it without deleting its registration; project deletion is broader.
