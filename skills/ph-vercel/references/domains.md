# Domains

- Distinguish a domain registration, project-domain attachment, DNS record, and deployment alias.
- Resolve the actual authoritative DNS provider before editing. Assigning an alias can move live traffic.
- Check current registrar price and requested transaction before any paid registration or transfer.
- Transfer authorization codes are secrets. Inspect verification/TLS status without exposing them.
- Deleting a certificate can break HTTPS for every bound hostname.
