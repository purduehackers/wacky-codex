# Observability

- Scope runtime logs to project/deployment, environment, and time window. Application exceptions belong in Sentry when that evidence is available.
- Distinguish configurable log drains, integration-created drains, and data drains. Removing a drain stops delivery to its consumer.
- Inspect current observability settings and billing before enabling paid features.
- Use team audit events for who/when configuration questions and retain the relevant event IDs.
