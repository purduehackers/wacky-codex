# Team admin

- Resolve member IDs, access-group membership, and project roles before changing access.
- Deleting a group revokes its project access; deleting a webhook interrupts its consumers.
- Inspect project routes, private networks, and microfrontend groups in their actual project/team scope.
- Bound billing queries with explicit dates and distinguish usage from contract commitments.
- Custom environments can own branch-specific variables. Inspect the effect on unassigned variables before removing an environment.
