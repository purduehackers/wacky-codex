# Dev resources

- Dev resources attach code, documentation, or Storybook links to specific design nodes.
- Resolve file and node IDs, inspect existing links, then create or update the requested named URL.
- Removing a resource deletes the design annotation, not its linked code or document.

A dev resource associates a URL and name with a specific file/node pair.
Use it for code, documentation, or Storybook links. Updating the URL/name
should preserve the node association; a comment pin is a different object.
