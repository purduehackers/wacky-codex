# Nodes

- Start with file metadata or a shallow tree, then inspect specific node IDs. Avoid dumping an entire large file.
- Use the connected provider's design-context and render tools, following its installed skill requirements.
- Distinguish rendered node exports from source image fills. Select raster scale or vector/PDF output for the requested use.
- Export URLs can expire. Verify the returned artifact and retain a durable file when the user needs a deliverable.
