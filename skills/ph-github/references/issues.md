# Issues

- Use a concise title and factual, self-contained body. Set assignees, labels, and milestones only when requested or clearly implied.
- Preserve existing body text when adding information; many updates replace the entire body.
- Read the relevant discussion before an authorized comment. Closing/reopening differs from locking/unlocking discussion.
- Resolve existing labels and milestones, including scope and due date, before creating duplicates.
