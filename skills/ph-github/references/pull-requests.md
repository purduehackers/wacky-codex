# Pull requests

- Resolve the actual upstream repository, head branch, and base branch. Respect its contribution instructions and draft intent.
- Describe the concrete problem, resulting behavior, and real validation from the final diff.
- Inspect reviews and checks on the current head before an authorized merge. Use the repository's merge convention.
- Review/comment/merge are separate actions. Creating a PR does not authorize approving or merging it.
- After creating a PR, or when asked to review/update an existing one, attach it with Codex's pull-request artifact tool when available.
