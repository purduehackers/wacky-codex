Default organization: purduehackers. Use GitHub MCP or the connected plugin; use gh/local Git for supported gaps and code work.

Verify the remote, upstream, branch, and repository instructions before editing. Preserve local work and use normal Git validation.

Resolve identities and scopes before writes. Use existing authorization; read-only inspection does not imply posting, publishing, or merging.

Read only the relevant topic below. These are PH workflows; discover the connected
provider's current tools and input schemas instead of assuming a tool name.

- [Actions](references/actions.md): List and manage workflows, workflow runs, jobs, and artifacts.
- [Collaborators](references/collaborators.md): Manage direct repository collaborators and pending invitations (admin only for writes).
- [Contents](references/contents.md): Read and write file contents; browse directory trees; view commits and diffs.
- [Deployments](references/deployments.md): Manage deployments, deployment statuses, and GitHub Pages.
- [Environments](references/environments.md): Manage deployment environments — protection rules, wait timers, required reviewers.
- [Issues](references/issues.md): Create, update, and manage issues; manage labels and milestones.
- [Membership](references/membership.md): Invite or remove members from the purduehackers GitHub organization (admin only).
- [Organization](references/organization.md): View organization members and teams; manage team membership and webhooks.
- [Packages](references/packages.md): List, inspect, and manage organization packages.
- [Projects](references/projects.md): Manage GitHub Projects v2 — list projects, view and manage items.
- [Pull requests](references/pull-requests.md): Create, update, review, and merge pull requests.
- [Reactions](references/reactions.md): Add or remove reaction emojis on issues and issue/PR comments.
- [Releases](references/releases.md): Manage GitHub releases — list, create, update, and delete releases and their assets.
- [Repositories](references/repositories.md): Create, update, and delete repositories; manage branches and branch protection.
- [Secrets and variables](references/secrets-and-variables.md): Manage repository and organization secrets and variables for GitHub Actions.
- [Tags refs](references/tags-refs.md): Manage git refs (branches and tags) — list, create, update, and delete.
