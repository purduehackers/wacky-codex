Use Notion MCP/plugin. Resolve the intended page and actual data source before querying or writing.

Inspect schemas and current provider input shapes. Database containers, data sources, and views are not interchangeable.

Prefer native Notion Markdown for page editing, preserve unrelated content, and link the resulting pages.

Read only the relevant topic below. These are PH workflows; discover the connected
provider's current tools and input schemas instead of assuming a tool name.

- [Blocks](references/blocks.md): Read and modify individual Notion blocks — retrieve, update, archive, list children, and append.
- [Comments](references/comments.md): Create and list comments on pages and blocks.
- [Databases](references/databases.md): Query database entries with filters/sorts; create and update databases.
- [Pages](references/pages.md): Create, update, read, and edit pages — properties and Notion-flavored markdown content.
