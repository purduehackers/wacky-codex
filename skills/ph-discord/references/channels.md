# Channels

- Resolve the channel and parent category, then choose the requested text, voice, category, announcement, forum, or stage type.
- Set only requested fields. Category moves use a parent ID; clearing a parent requires the provider's explicit clear value.
- Voice/stage settings differ from text settings. Read the current tool schema for bitrate, user limits, topics, and slowmode.
- Deleting a channel loses its history; deleting a category leaves child channels uncategorized. Identify the exact target before an authorized deletion.
