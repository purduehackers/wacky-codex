# Threads

- Distinguish a Discord thread from a Codex chat. Read active threads and request archived history only when needed.
- Create under a channel, optionally attached to a specific message; choose public/private and supported auto-archive duration.
- Threads cannot contain other threads. Archiving hides a thread from active lists while preserving its content.
- Deleting a thread removes its messages. Locking, archiving, and deleting are separate operations.
