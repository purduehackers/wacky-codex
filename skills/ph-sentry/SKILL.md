Organization: purduehackers. Use Sentry MCP and discover project slugs and actual capabilities.

Application exceptions, traces, and user impact belong here; build/deployment/platform failures route to ph-vercel.

Distinguish numeric issue IDs from short IDs such as PROJECT-123. Bound queries by project, environment, and time, and link evidence.

Read only the relevant topic below. These are PH workflows; discover the connected
provider's current tools and input schemas instead of assuming a tool name.

- [Alerts](references/alerts.md): List, create, update, and delete issue and metric alert rules.
- [Events](references/events.md): List and inspect error events, stack traces, and breadcrumbs.
- [Issue management](references/issue-management.md): Update, resolve, ignore, assign, delete, and tag issues.
- [Log search](references/log-search.md): Search structured logs and inspect log volume over time.
- [Members](references/members.md): List and manage organization members and teams; view team membership.
- [Membership](references/membership.md): Invite new members to the Sentry organization or remove existing ones (admin only).
- [Metrics](references/metrics.md): Query custom metrics — counters, distributions, gauges, and sets.
- [Monitors](references/monitors.md): Manage cron monitors — view schedules, check-in history, and configure runtime limits.
- [Performance](references/performance.md): Query transaction performance, latency, throughput, and span data.
- [Profiling](references/profiling.md): View CPU profiling data — flamegraphs and slowest functions.
- [Projects management](references/projects-management.md): Create, update, and delete Sentry projects; manage project environments and client keys (DSNs).
- [Releases](references/releases.md): Create and manage releases and deploys; view release health and commits.
- [Replays](references/replays.md): View session replays — user session recordings with error context.
- [Stats](references/stats.md): View organization and project usage statistics — event volume, quotas, and trends.
- [Traces](references/traces.md): View distributed traces — full request waterfalls across services.
