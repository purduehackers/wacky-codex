# Customer requests

- Resolve the customer and related issue or project. Preserve the customer's actual request without adding commitments.
- Inspect the current customer-request schema for importance and state.
- For analysis, group themes with links to supporting requests; distinguish distinct customers from repeated requests.

Linear also calls these customer needs. Attach a need to the intended issue
or project and resolve the customer independently. Wack represented importance
as 0 (not important) or 1 (important); map this to the current provider schema,
not issue priority (which uses a different scale).
