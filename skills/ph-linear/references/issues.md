# Issues

- Write a concise single-line title and factual, self-contained description.
- PH's default is to assign a new issue to the requesting organizer unless another owner or no owner is requested. Resolve their connected Linear identity first.
- Resolve the team's workflow state. Priorities are 0 none, 1 urgent, 2 high, 3 normal, and 4 low.
- Preserve existing description text and unrelated fields during an edit. Resolve dependency direction before linking blocking/blocked issues.
- Prefer archive for reversible removal. Read issue history for field changes and comments for discussion; they answer different questions.
